- # Web Vulnerability Analysis 🔍  

## 📌 About  
This project analyzes web application security vulnerabilities using **Burp Suite, SQL Injection, and XSS attacks**.  

## 🔧 Tools Used  
- **Burp Suite** (Intercept HTTP Requests)  
- **Nmap** (Network Scanning)  
- **SQLMap** (SQL Injection Testing)  
- **Dirb** (Directory Enumeration)  

## 🚀 Steps Performed  
1. **Reconnaissance:** Identified open ports and services.  
2. **Scanning:** Used Nmap & Dirb for directory enumeration.  
3. **Exploitation:** Tested for SQL Injection & XSS vulnerabilities.  
4. **Reporting:** Suggested mitigation techniques.
